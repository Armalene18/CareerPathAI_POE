# CareerPathAI_POE
### AI-Powered Career Exploration Android Application

CareerPathAI is an Android application developed to help users explore career opportunities, identify potential career paths and make informed decisions about their academic and professional development.

The application provides a mobile platform where users can create accounts, complete career-related assessments and explore career recommendations based on their interests, skills and preferences.

## 🏗️ Application Architecture

CareerPathAI uses an Android-based application architecture.

The Android application is responsible for displaying the user interface, collecting user input and communicating with Firebase services.

Firebase Authentication manages user authentication, while Cloud Firestore provides cloud-based storage and retrieval of application data.


## 📱 Application Requirements

To run the project, you will need:

- Android Studio.

## ⚙️ Installation and Setup

Follow these instructions to run CareerPathAI locally.

**Step 1: Clone the repository**

```bash
git clone https://github.com/Armalene18/CareerPathAI-POE.git
```

**Step 2: Open the project**

1. Open Android Studio.
2. Select **Open**.
3. Locate the cloned CareerPathAI project.
4. Allow Gradle to synchronise.

**Step 3: Configure Firebase**

1. Open the Firebase Console.
2. Create or select your Firebase project.
3. Register the Android application using its package name.
4. Download the `google-services.json` configuration file.
5. Place the file inside the app directory.
6. Enable Email/Password authentication.
7. Configure Cloud Firestore.

**Step 4: Build and run**

1. Connect an Android device or start an emulator.
2. Allow USB debugging if using a physical device.
3. Select the application run configuration.
4. Click **Run** in Android Studio.


## 🔥 Firebase Integration

CareerPathAI uses Firebase services to support its cloud functionality.

**Firebase Authentication**
- Manages user registration.
- Handles email and password login.
- Supports account authentication.

**Cloud Firestore**
- Stores user profile information.
- Stores completed assessment information.
- Supports retrieving previously saved assessment results.
- Stores application preferences where configured.
